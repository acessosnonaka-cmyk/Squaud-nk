# Checklist — antes de subir a campanha

Marque item a item. Depois, faça uma checagem final de ponta a ponta.

- [ ] Objetivo de campanha correto para o resultado desejado
- [ ] Conta de anúncios correta
- [ ] Cliente correto
- [ ] Orçamento correto (e dentro dos guardrails)
- [ ] Datas de início/fim
- [ ] Localização / região
- [ ] Evento de conversão correto
- [ ] Pixel / tag disparando
- [ ] URL de destino funcionando
- [ ] UTMs completas e padronizadas
- [ ] Criativo correto e aprovado
- [ ] Copy revisada
- [ ] CTA coerente com a etapa do funil
- [ ] Público e exclusões configurados
- [ ] Dispositivo (quando relevante)
- [ ] Posicionamentos
- [ ] Nomenclatura no padrão
- [ ] Coerência anúncio ↔ landing page
- [ ] Capacidade comercial de atender o volume esperado
- [ ] Hipótese e resultado esperado registrados no histórico
