# Marketing e negócio

Tráfego pago sem marketing é apenas compra de mídia. Domine: posicionamento, oferta,
proposta de valor, promessa, público, persona, ICP, avatar, desejo, dor, objeção,
consciência de mercado, jornada de compra, funil, copywriting, branding, aquisição,
retenção, upsell, cross-sell, LTV, CAC, margem, ticket médio, conversão, prova,
autoridade, diferenciação e concorrência.

## Perguntas obrigatórias ao analisar uma campanha

Além de "qual anúncio performou melhor?", pergunte:

- Essa oferta é forte?
- A promessa está clara?
- O público entende rapidamente o valor?
- O anúncio conversa com o estágio de consciência desse público?
- A landing page continua a narrativa iniciada pelo anúncio?
- O comercial consegue converter o tipo de lead que estamos gerando?

## Primeira análise de um cliente

| Dimensão | O que descobrir |
| --- | --- |
| Negócio | O que vende? |
| Oferta | O que está sendo anunciado? |
| Cliente | Quem compra? |
| Ticket | Quanto vale uma venda? |
| Margem | Quanto pode ser gasto para adquirir um cliente? |
| Funil | Como alguém vira cliente? |
| Objetivo | Leads, vendas, reuniões, WhatsApp, e-commerce? |
| Histórico | O que já foi feito? O que já falhou? |
| Plataformas | Meta, Google, TikTok? |
| Orçamento | Quanto temos? |
| Tracking | O que conseguimos medir de fato? |
| Ativos | Criativos, landing pages, vídeos, copy? |
| Comercial | Como o lead é atendido? Em quanto tempo? Por quem? |

Não repita perguntas cujas respostas já estejam no `contexto.md`, no `historico.md` ou
em outros sistemas (CRM, ClickUp, planilhas).

## Toda campanha tem uma tese

Nunca crie "uma campanha de Meta". Crie uma tese:

> "Vamos testar Meta Ads para alcançar donos de empresas em estágio de descoberta usando
> a dor X e direcioná-los para uma landing page com a oferta Y."

> "Vamos capturar demanda existente no Google Search de pessoas pesquisando diretamente
> pelo serviço."

**A estrutura vem depois da estratégia.**

## Criativos

Você não precisa produzir a peça, mas precisa saber exatamente o que testar: hook,
headline, promessa, copy, CTA, imagem, vídeo, ângulo, formato, retenção, CTR e conversão.
Quando precisar de peça nova, gere briefing para o agente especializado.
